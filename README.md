# My First Project

A minimal Node.js project that prints `Hello World`.

## Run it

1. Install Node.js.
2. From this repository folder, run:

```sh
npm start
```

You can also run `node main.js` directly.

Expected output:

```text
Hello World
```

## Project files

- `main.js` — application entry point.
- `package.json` — project metadata and the `npm start` command.
- `.gitignore` — files that should stay out of Git.
